# Лабораторные работы по операционным системам

Для сборки нужны Linux, компилятор C (GCC или Clang) и `make`. Для просмотра системных вызовов дополнительно нужен `strace`.

Оба примера ниже начинаются из корня репозитория.

## ЛР2 — процессы и каналы

Команды запускайте из каталога `lab_2`, потому что родитель ищет `./build/child` относительно текущего каталога:

```sh
cd lab_2
make
printf '/tmp/sums.txt\n1 2 3\n-5 10\n' | ./build/parent
cat /tmp/sums.txt
cd ..
```

## ЛР3 — многопоточная битоническая сортировка

```sh
cd lab_3
make
printf '7 9 -2 4 4 0 7 -8\n' | ./build/bitonic --threads 3
```

Подробности запуска и результаты измерений находятся в `lab_2/README.md`, `lab_3/README.md` и каталогах `report`.
