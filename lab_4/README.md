# Лабораторная работа №4 — обмен через отображаемый файл, вариант 1

Задача такая же, как в ЛР2: родитель получает имя файла и строки целых чисел, ребёнок считает сумму каждой корректной строки и записывает её в файл. В этой работе данные между процессами передаются через `mmap(MAP_SHARED)`, а сигналы `SIGUSR1` и `SIGUSR2` уведомляют о новой строке и готовом ответе.

## Сборка и запуск

Программа предназначена для Linux. Из каталога `lab_4`:

```sh
make
printf '/tmp/sums.txt\n1 2 3\n-5 10\n' | ./build/parent
cat /tmp/sums.txt
```

Результат в файле — `6` и `5`. При интерактивном запуске сначала введите имя файла, затем строки чисел; `Ctrl+D` завершает ввод. PID родителя и ребёнка выводятся в `stderr`.

## Как устроен обмен

Родитель создаёт временный файл через `mkstemp`, сразу удаляет его имя через `unlink` и передаёт открытый дескриптор отдельной программе `child` через `fork` и `execl`. Файл остаётся доступным обоим процессам, пока открыты их дескрипторы. Для каждой строки родитель задаёт размер файла через `ftruncate`, отображает его через `mmap`, записывает строку и посылает ребёнку `SIGUSR1`. Ребёнок отображает тот же файл, читает строку, записывает сумму в файл результатов и посылает `SIGUSR2`. Родитель отправляет следующую строку только после ответа.

Размер отображения зависит от длины строки; фиксированного предела на число элементов в команде нет. Состояние запроса хранится в общей атомарной переменной. `msync` здесь не нужен: `MAP_SHARED` делает изменения видимыми через общее отображение, а `msync` нужен для их записи на носитель. При ошибке открытия файла или завершении ребёнка родитель получает `SIGCHLD`, сообщает об ошибке и вызывает `waitpid`.

## Наблюдение в Linux

```sh
strace -ff -e trace=openat,unlinkat,ftruncate,mmap,munmap,clone,execve,kill,rt_sigtimedwait,wait4 -o /tmp/lab4.trace ./build/parent
```

В трассах ищите `ftruncate` и `mmap` с `MAP_SHARED` у обоих процессов, `kill` с `SIGUSR1`/`SIGUSR2`, ожидание `rt_sigtimedwait` и завершение `wait4`. Ключ `-ff` сохраняет отдельный файл трассы для каждого PID.
