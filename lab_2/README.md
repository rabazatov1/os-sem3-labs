# Лабораторная работа №2 — процессы и каналы, вариант 1

Родитель принимает имя файла и строки целых чисел. Он передаёт строки дочерней программе через `pipe1`. Дочерняя программа считает сумму каждой корректной строки и записывает её в файл. Короткие ответы возвращаются через `pipe2`.

```text
пользователь → parent → pipe1 → child → файл результатов
                 parent ← pipe2 ← child
```

Первый ответ ребёнка `R` означает, что файл открыт. После каждой строки он возвращает `O` (сумма записана) или `E` (ошибка строки или записи). Родитель ждёт ответ перед отправкой следующей строки. При конце ввода он закрывает канал команд и вызывает `waitpid`.

## Сборка и запуск

Из каталога `lab_2`:

```sh
make
./build/parent
```

Первой строкой введите имя файла, затем строки чисел через пробел. `Ctrl+D` завершает ввод. Пример без ручного ввода:

```sh
printf '/tmp/sums.txt\n1 2 3\n-5 10\n' | ./build/parent
cat /tmp/sums.txt
```

В файле будут строки `6` и `5`. Программа проверяет некорректные числа и переполнение `int`. В консоль выводятся PID обоих процессов; диагностические сообщения ребёнка идут в `stderr`.

Для наблюдения системных вызовов в Linux:

```sh
strace -f -e trace=pipe,pipe2,clone,clone3,dup2,dup3,execve,openat,read,write,close,wait4 ./build/parent
```

`-f` включает дочерний процесс. В трассе можно найти создание двух каналов, `fork` (через `clone`), перенаправление `dup2` (на этой системе через `dup3`), запуск `child` с `execve`, запись в файл и ожидание `wait4`.
