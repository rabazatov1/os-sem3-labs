# Лабораторная работа №5 — динамические библиотеки, вариант 1

Две библиотеки реализуют одинаковые функции `SinIntegral` и `Derivative` разными численными методами. `program1` использует первую библиотеку при компоновке. `program2` загружает библиотеки через `dlopen` и переключает их во время работы.

## Сборка и запуск

Нужны Linux, компилятор C, `make` и математическая библиотека `libm`. Команды выполняются из каталога `lab_5`:

```sh
make
printf '1 0 1 0.25\n2 1 0.1\n' | ./build/program1
printf '1 0 1 0.25\n0\n1 0 1 0.25\n' | ./build/program2
```

Формат ввода — одна команда в строке:

| Команда | Действие |
|---|---|
| `1 A B e` | Интеграл `sin(x)` от `A` до `B` с положительным шагом `e` |
| `2 A deltaX` | Производная `cos(x)` в точке `A`, `deltaX` не равно нулю |
| `0` | Переключить реализацию в `program2` |

При запуске `program2` активна реализация 1. Программа читает команды до конца ввода (`Ctrl+D`). Результаты печатаются в `stdout`, сообщения об ошибках — в `stderr`. Неверная строка не прерывает дальнейший ввод. Оба аргумента интервала могут идти в обратном порядке: знак интеграла меняется.

`program2` ищет библиотеки по относительным путям `./build/libimpl1.so` и `./build/libimpl2.so`, поэтому его нужно запускать из каталога `lab_5`. Для `program1` путь к `libimpl1.so` задан через `$ORIGIN`, то есть относительно самого исполняемого файла.

## Реализации

| Функция | Библиотека 1 | Библиотека 2 |
|---|---|---|
| `SinIntegral` | Левые прямоугольники | Трапеции |
| `Derivative` | Правая конечная разность | Центральная конечная разность |

Последний участок интегрирования укорачивается, если длина интервала не кратна шагу. Внутри библиотек вычисления ведутся в `double`, а интерфейс возвращает `float`, как требует задание. Значения должны быть конечными; шаг интегрирования должен быть положительным, приращение производной — ненулевым.
